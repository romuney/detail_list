форке Superset) в быстрые борды без нативных фильтров: фильтры внутри кастомного чарта

отсюда недоступны.

## Ограничения

- ClickHouse в бою — 24.8 (стенд — chdb 2.1.1; в его сборке нет `base64Encode`): без
  `SETTINGS` в датасете, без неконстантных WITH-алиасов в подзапросах, `ifNull` на каждой
  колонке (источник весь Nullable), подзапрос и CTE переисполняются на каждой ссылке.
- Доступ — warden (`warden_access_array_cross` по `current_username()`) маскирует
  персональные данные, грейд, сеньорность и оценку; новая схема — не слабее текущей.
- Сначала отобрать, потом упаковать: маски, чистка и упаковка — только для строк, которые
  уйдут в ответ, и только по видимым колонкам.
- Без вспомогательных датасетов: значения фильтров, деревья УС / ЮС / КП и поиск юнита
  считает тот же датасет из самой таблицы списка (УС и ЮС — по rk уровней, КП — по пути
  имён); `cross_filter_*_structure` и датасеты нативных фильтров не используем.
- Кросс-фильтры: носители в SELECT не выводятся, `value = []` не эмитится, у чарта
  включено самовлияние (сам чарт убран из `excluded`).
- Чарт — ES5 по шаблону скилла, состояние — в `window.__pvtState`; base64 — встроенными
  `atob` + `TextDecoder`, не посимвольным циклом.
- Скратч (синтетика, замеры, пробный SQL) в репозиторий не кладём — только выводы в `docs/`.
