# CLAUDE.md

Переделка отчёта Proteus (корпоративный BI, форк Superset) в быстрые борды без нативных
фильтров: фильтры внутри кастомного чарта `react_sanbbox`, один датасет, один запрос на
открытие и на «Применить», список — из памяти браузера. Боевые системы (ClickHouse,
Proteus) отсюда недоступны.

Сейчас: разбор выгрузки, схема и замеры — **`docs/analysis.md`** (читать первым).
Реализации нет, ждём ответов на вопросы его раздела 8.

## Ограничения

- ClickHouse в бою — 24.8 (стенд — chdb 2.1.1): без `SETTINGS` в датасете, без
  неконстантных WITH-алиасов в подзапросах, `ifNull` на каждой колонке (источник весь
  Nullable), подзапрос и CTE переисполняются на каждой ссылке.
- Кросс-фильтры: носители в SELECT не выводятся, `value = []` не эмитится, у чарта
  включено самовлияние (сам чарт убран из `excluded`).
- Чарт — ES5 по шаблону скилла, состояние — в `window.__pvtState`.
- Список не отдаётся записями: строки пачками (поля через табуляцию, строки через
  перевод строки), категории — номером значения из фасетов.
- Скратч (синтетика, замеры, пробный SQL) в репозиторий не кладём — только выводы в `docs/`.
